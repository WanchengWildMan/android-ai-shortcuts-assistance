# 无障碍服务架构说明

## 概述

本项目采用了**独立应用**的无障碍服务架构，将无障碍服务运行在独立的提供者应用中，主应用通过 AIDL 进行跨进程通信。

### 架构优势

1. **降低检测风险**：某些应用会检测无障碍服务并封号，独立应用可以降低主应用的检测风险
2. **权限隔离**：无障碍服务运行在独立进程中，权限隔离更安全
3. **灵活更新**：可以独立更新无障碍服务提供者应用

## 架构组件

### 1. 主应用组件

#### IAccessibilityProvider.aidl
位置：`app/src/main/aidl/com/autoglm/assistant/provider/IAccessibilityProvider.aidl`

定义了主应用与提供者应用之间的 AIDL 接口：
- `performClick(x, y)` - 点击操作
- `performLongPress(x, y)` - 长按操作
- `performSwipe(startX, startY, endX, endY, duration)` - 滑动操作
- `getUiHierarchy()` - 获取 UI 层次结构
- `isAccessibilityServiceEnabled()` - 检查服务状态

#### UIHierarchyManager.kt
位置：`app/src/main/java/com/autoglm/assistant/accessibility/UIHierarchyManager.kt`

核心管理器，负责：
- 绑定到提供者应用的服务
- 执行跨进程的操作调用
- 管理服务连接状态
- 处理 APK 提取与安装

#### AccessibilityProviderInstaller.kt
位置：`app/src/main/java/com/autoglm/assistant/accessibility/AccessibilityProviderInstaller.kt`

安装管理器，负责：
- 检查提供者应用是否已安装
- 比较版本号判断是否需要更新
- 提供安装入口

### 2. 资源文件

#### accessibility_version.txt
位置：`app/src/main/assets/accessibility_version.txt`

存储内置的提供者应用版本号，格式为语义化版本号（如 `1.0.0`）。

#### accessibility_provider.apk
位置：`app/src/main/assets/accessibility_provider.apk`（需自行添加）

独立的无障碍服务提供者应用 APK 文件。

#### file_paths.xml
位置：`app/src/main/res/xml/file_paths.xml`

FileProvider 配置文件，用于安全地共享 APK 文件进行安装。

## 使用方法

### 1. 准备提供者应用

首先需要创建一个独立的无障碍服务提供者应用，包名必须为 `com.autoglm.assistant.provider`。

提供者应用需要实现：
- 继承 `AccessibilityService` 的服务类
- 实现 `IAccessibilityProvider.aidl` 中定义的所有接口
- 在 `AndroidManifest.xml` 中声明服务并导出

### 2. 检查安装状态

```kotlin
import com.autoglm.assistant.accessibility.UIHierarchyManager
import com.autoglm.assistant.accessibility.AccessibilityProviderInstaller

// 检查提供者应用是否已安装
val isInstalled = UIHierarchyManager.isProviderAppInstalled(context)

if (!isInstalled) {
    // 启动安装流程
    UIHierarchyManager.launchProviderInstall(context)
}
```

### 3. 检查版本更新

```kotlin
// 获取已安装版本
val installedVersion = AccessibilityProviderInstaller.getInstalledVersion(context)

// 获取内置版本
val bundledVersion = AccessibilityProviderInstaller.getBundledVersion(context)

// 检查是否需要更新
val needsUpdate = AccessibilityProviderInstaller.isUpdateNeeded(context)

if (needsUpdate) {
    // 提示用户更新
    AccessibilityProviderInstaller.launchInstall(context)
}
```

### 4. 绑定服务

```kotlin
import kotlinx.coroutines.launch
import kotlinx.coroutines.Dispatchers

lifecycleScope.launch(Dispatchers.IO) {
    // 绑定到提供者服务
    val success = UIHierarchyManager.bindToService(context)
    
    if (success) {
        Log.d("App", "服务绑定成功")
    } else {
        Log.e("App", "服务绑定失败")
    }
}
```

### 5. 执行操作

```kotlin
lifecycleScope.launch(Dispatchers.IO) {
    // 确保服务已绑定
    if (UIHierarchyManager.bindToService(context)) {
        
        // 执行点击
        val clickSuccess = UIHierarchyManager.performClick(context, 500, 800)
        
        // 执行滑动
        val swipeSuccess = UIHierarchyManager.performSwipe(
            context,
            startX = 500,
            startY = 1000,
            endX = 500,
            endY = 500,
            duration = 300
        )
        
        // 获取 UI 层次结构
        val uiHierarchy = UIHierarchyManager.getUIHierarchy(context)
        
        // 检查服务状态
        val isEnabled = UIHierarchyManager.isAccessibilityServiceEnabled(context)
    }
}
```

### 6. 解绑服务

```kotlin
// 在不需要时解绑服务以释放资源
UIHierarchyManager.unbindFromService(context)
```

## 集成到现有项目

### 步骤1：添加 APK 文件

将编译好的提供者应用 APK 放入：
```
app/src/main/assets/accessibility_provider.apk
```

### 步骤2：更新版本文件

编辑 `app/src/main/assets/accessibility_version.txt`，填入提供者应用的版本号：
```
1.0.0
```

### 步骤3：在代码中使用

参考上述"使用方法"部分的示例代码。

## 注意事项

### 包名一致性 (HARD)

以下位置的包名必须完全一致：
- `UIHierarchyManager.kt` 中的 `PROVIDER_PACKAGE_NAME`
- `AccessibilityProviderInstaller.kt` 中的 `ACCESSIBILITY_PACKAGE_NAME`
- 提供者应用的实际包名

当前配置的包名为：`com.autoglm.assistant.provider`

### Action 一致性 (HARD)

`UIHierarchyManager.kt` 中的 `PROVIDER_ACTION` 必须与提供者应用在 `AndroidManifest.xml` 中声明的 Action 一致。

当前配置的 Action 为：`com.autoglm.assistant.provider.IAccessibilityProvider`

### 权限要求

1. 主应用需要在运行时请求 `REQUEST_INSTALL_PACKAGES` 权限（Android 8.0+）
2. 提供者应用需要用户在系统设置中手动启用无障碍服务

### 文件位置

确保以下文件存在：
- `app/src/main/assets/accessibility_provider.apk`
- `app/src/main/assets/accessibility_version.txt`

## 故障排除

### 服务绑定失败

1. 检查提供者应用是否已安装
2. 检查包名和 Action 是否一致
3. 检查提供者应用的服务是否正确导出
4. 查看 Logcat 中的详细错误信息

### 操作执行失败

1. 确认无障碍服务已在系统设置中启用
2. 检查提供者应用的无障碍服务实现
3. 确认操作的坐标是否在屏幕范围内

### 版本检查异常

1. 确认 `accessibility_version.txt` 文件存在且格式正确
2. 确认提供者应用的 `versionName` 格式为语义化版本号
3. 清除缓存：`AccessibilityProviderInstaller.clearCache()`
