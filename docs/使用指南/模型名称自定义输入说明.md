### 方法 1：直接修改 SharedPreferences（推荐）

```bash
# 设置协调器模型名称
adb shell run-as com.autoglm.assistant \\
  "echo '<string name=\"coordinator_model_name\">your-custom-model</string>' >> /data/data/com.autoglm.assistant/shared_prefs/autoglm_prefs.xml"

# 设置优化器模型名称
adb shell run-as com.autoglm.assistant \\
  "echo '<string name=\"optimizer_model_name\">your-custom-model</string>' >> /data/data/com.autoglm.assistant/shared_prefs/autoglm_prefs.xml"

# 重启 App
adb shell am force-stop com.autoglm.assistant
```

3. **替换 UI 组件**

   将第1400-1445行的 `ExposedDropdownMenuBox` 替换为：

   ```kotlin
   // 可编辑的模型名称输入框
   OutlinedTextField(
       value = coordinatorModelName,
       onValueChange = { coordinatorModelName = it },
       label = { Text(strings.coordinatorModelLabel) },
       modifier = Modifier.fillMaxWidth(),
       singleLine = true,
       supportingText = { Text("可以输入任意模型名称") }
   )

   // 快捷选择按钮
   Text(
       text = "快捷选择：",
       style = MaterialTheme.typography.bodySmall,
       modifier = Modifier.padding(top = 8.dp, bottom = 4.dp)
   )
   FlowRow(
       modifier = Modifier.fillMaxWidth(),
       horizontalArrangement = Arrangement.spacedBy(8.dp)
   ) {
       coordinatorModels.forEach { (model, displayName) ->
           FilterChip(
               selected = coordinatorModelName.text == model,
               onClick = {
                   coordinatorModelName = TextFieldValue(model)
                   // Auto-switch API URL and Key
                   coordinatorApiUrl = when {
                       model.startsWith("deepseek") -> TextFieldValue("https://api.deepseek.com/v1")
                       model.startsWith("glm-") -> TextFieldValue("https://open.bigmodel.cn/api/paas/v4")
                       model.startsWith("doubao") -> TextFieldValue("https://ark.cn-beijing.volces.com/api/v3")
                       else -> coordinatorApiUrl
                   }
                   coordinatorApiKey = when {
                       model.startsWith("deepseek") -> TextFieldValue(prefs.coordinatorApiKeyDeepseek)
                       model.startsWith("glm-") -> TextFieldValue(prefs.coordinatorApiKeyBigmodel)
                       model.startsWith("doubao") -> TextFieldValue(prefs.coordinatorApiKeyDoubao)
                       else -> coordinatorApiKey
                   }
               },
               label = { Text(displayName) }
           )
       }
   }
   ```

| 提供商 | 自定义模型名称 |
|--------|---------------|
| DeepSeek | `deepseek-reasoner`, `deepseek-chat` |

| Anthropic | `claude-3-opus-20240229`, `claude-3-sonnet-20240229` |
| Google | `gemini-pro`, `gemini-pro-vision` |
| 智谱 | `glm-4v-plus`, `glm-4-air`, `glm-4-airx` |
| 阿里 | `qwen-max`, `qwen-plus`, `qwen-turbo` |

## 注意事项

1. 自定义模型名称必须与 API 提供商支持的模型名称完全一致
2. 修改模型名称后需要重启服务才能生效
3. 如果使用不支持 vision 的模型，记得关闭 `enableVision` 配置
