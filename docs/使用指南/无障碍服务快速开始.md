# 无障碍服务快速开始 Checklist

## ✅ 主应用集成清单

### 步骤 1：确认文件已创建
- [x] `app/src/main/aidl/com/autoglm/assistant/provider/IAccessibilityProvider.aidl`
- [x] `app/src/main/java/com/autoglm/assistant/accessibility/UIHierarchyManager.kt`
- [x] `app/src/main/java/com/autoglm/assistant/accessibility/AccessibilityProviderInstaller.kt`
- [x] `app/src/main/res/xml/file_paths.xml`
- [x] `app/src/main/assets/accessibility_version.txt`
- [x] AndroidManifest.xml 中已添加 FileProvider 配置

### 步骤 2：添加提供者应用 APK
- [ ] 创建独立的提供者应用项目（参考：[Provider应用实现指南.md](./Provider应用实现指南.md)）
- [ ] 编译提供者应用生成 APK
- [ ] 将 APK 重命名为 `accessibility_provider.apk`
- [ ] 复制到 `app/src/main/assets/accessibility_provider.apk`
- [ ] 更新 `app/src/main/assets/accessibility_version.txt` 为对应版本号（如 `1.0.0`）

### 步骤 3：配置包名和 Action（HARD）
确认以下位置的配置一致：

**主应用 - UIHierarchyManager.kt**
```kotlin
private const val PROVIDER_PACKAGE_NAME = "com.autoglm.assistant.provider"
private const val PROVIDER_ACTION = "com.autoglm.assistant.provider.IAccessibilityProvider"
```

**主应用 - AccessibilityProviderInstaller.kt**
```kotlin
private const val ACCESSIBILITY_PACKAGE_NAME = "com.autoglm.assistant.provider"
```

**提供者应用 - AndroidManifest.xml**
```xml
<intent-filter>
    <action android:name="com.autoglm.assistant.provider.IAccessibilityProvider" />
</intent-filter>
```

**提供者应用 - build.gradle.kts**
```kotlin
applicationId = "com.autoglm.assistant.provider"
```

### 步骤 4：在代码中集成
参考 [AccessibilityExample.kt](../app/src/main/java/com/autoglm/assistant/example/AccessibilityExample.kt)

**最简单的使用示例：**
```kotlin
import com.autoglm.assistant.accessibility.UIHierarchyManager
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.launch

// 在协程中使用
lifecycleScope.launch(Dispatchers.IO) {
    // 1. 绑定服务
    if (UIHierarchyManager.bindToService(context)) {
        // 2. 执行点击
        val success = UIHierarchyManager.performClick(context, x = 500, y = 800)
        
        if (success) {
            Log.d("App", "点击成功")
        }
    }
}
```

- [ ] 安装到设备：`./gradlew installDebug`

### 常见问题排查
- [ ] 服务绑定失败 → 检查包名和 Action 配置

- [ ] 版本检查异常 → 确认 accessibility_version.txt 存在且格式正确

## ⚠️ 重要提醒

### HARD 约束（不可变更）
1. 提供者应用包名必须为：`com.autoglm.assistant.provider`
2. AIDL 文件路径必须完全一致
3. Service 的 Action 必须与配置匹配

### 版本管理
- 提供者应用的 `versionName` 必须与 `accessibility_version.txt` 一致
- 使用语义化版本号格式（major.minor.patch）

### 安全建议
- 仅在开发和个人使用场景下使用
- 不建议在应用市场公开发布（可能违反政策）
- 注意保护用户隐私和数据安全
