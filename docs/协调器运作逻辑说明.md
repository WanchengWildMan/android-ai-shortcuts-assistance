# 协调器运作逻辑说明

## 📋 协调器的职责定位

协调器（SmartCoordinator）是一个**高层决策模块**，其核心职责是：

1. **分析当前状态**：根据执行历史和截图，判断任务进展
2. **规划下一步目标**：产出目标导向的自然语言指令
3. **判断任务状态**：决定继续/完成/失败

### ⚠️ 重要原则

**协调器不应该直接"do action"**，而应该：
- ✅ 输出**目标型指令**："打开地图应用"、"搜索星巴克"
- ❌ 不要输出**操作型指令**："点击第3个按钮"、"向下滑动200像素"

具体操作由 PhoneAgent 根据协调器的目标指令自主决策完成。

---

## 🔄 协调器的工作流程

### 1. 决策循环

```
while (coordinatorSteps < maxCoordinatorSteps && currentStep < maxSteps) {
    1️⃣ 协调器分析当前状态（截图 + 历史）
    2️⃣ 协调器输出决策（目标 + 状态）
    3️⃣ PhoneAgent 执行具体操作
    4️⃣ 返回步骤1，继续下一轮
}
```

### 2. 决策的三种状态

| 状态 | 说明 | 示例输出 |
|-----|------|---------|
| **CONTINUE** | 继续执行 | "打开地图应用" |
| **COMPLETE** | 任务完成 | "[COMPLETE] 已成功找到星巴克门店信息" |
| **FAILED** | 任务失败 | "[FAILED] 当前页面没有搜索功能" |

---

## 💬 协调器的输出格式

### 推荐格式：带思考标签

协调器应该输出**两部分内容**：

```
<thinking>
当前状态：用户在主页面
任务目标：搜索星巴克门店
分析：需要先打开地图应用才能搜索位置
下一步：打开地图应用
</thinking>
打开地图应用
```

- **`<thinking>` 标签内**：分析过程（显示给用户，帮助理解决策逻辑）
- **标签外正文**：决策结果（传递给PhoneAgent的目标指令）

---

## 🖥️ 用户界面显示

### 显示内容

1. **协调器分析**（`COORDINATOR_THINKING`）
   - 显示格式：🤔 **协调器分析：** [思考内容]
   - 内容来源：`<thinking>` 标签内的分析过程（自动格式化为自然语言）

2. **下一步目标**（`SUBTASK_START`）
   - 显示格式：**下一步目标：** [目标指令]
   - 内容来源：决策结果中的 `nextInstruction`

3. **执行步数**（`COORDINATOR_STEP`）
   - 显示格式：🔄 **协调器执行中** [3/20]
   - 表示当前是第几轮协调决策

### 不应该显示的内容

- ❌ 原始JSON格式
- ❌ 具体的点击坐标
- ❌ PhoneAgent的内部操作细节

## 🔧 最近修复内容

### 问题1：协调器也在"do action"

**❌ 原问题**：协调器的输出被当作操作指令直接显示

**✅ 修复方案**：
1. 协调器的`onCoordinatorThinking`回调现在会将分析过程发送到UI显示
2. 在UI中以"协调器分析"形式展示，与操作指令区分开
3. Prompt优化，明确要求输出目标型指令而非操作型指令

**代码位置**：
- [WakeWordService.kt](../app/src/main/java/com/autoglm/assistant/service/WakeWordService.kt#L363-L369)
- [MainActivity.kt](../app/src/main/java/com/autoglm/assistant/MainActivity.kt#L435-L437)

### 问题2：协调器完成后弹回主界面、显示JSON

**❌ 原问题**：
- 协调器的原始输出（可能含JSON）直接流式显示给用户
- 任务完成后没有正确处理状态

**✅ 修复方案**：
1. `onDecisionComplete`回调中区分任务继续/完成/失败状态
2. 只在继续状态时显示下一步目标
3. 完成/失败时触发步数清零，不再显示协调器输出
4. Prompt优化，要求不要输出JSON格式

**代码位置**：
- [WakeWordService.kt](../app/src/main/java/com/autoglm/assistant/service/WakeWordService.kt#L391-L410)
- [SmartCoordinator.kt](../app/src/main/java/com/autoglm/assistant/core/planner/SmartCoordinator.kt#L411-L458)

## 📝 Prompt配置说明

### 系统提示词结构

```
你是任务协调器。你的职责是分析当前状态并为 PhoneAgent 规划下一步目标。

你的输出分为两部分：

1. **思考过程**（<thinking>标签内）：
   - 分析当前状态和已执行步骤
   - 判断任务进度
   - 推理下一步应该达成什么目标
   
2. **输出决策**（正文）：
   - 继续执行：输出一行目标型指令
   - 任务完成：以 [COMPLETE] 开头
   - 任务失败：以 [FAILED] 开头

重要原则：
- 目标导向：指令只描述"要达成什么"，不描述"怎么做"
- 简洁明了：一行简短的目标描述
- 不要输出JSON格式
```

### 自定义Prompt位置

在设置界面 → 智能协调器配置 → 系统提示词

## 🎯 最佳实践

### ✅ 好的协调器输出

```
<thinking>
分析：用户想搜索星巴克门店
当前状态：在主页面
下一步：打开地图应用
</thinking>
打开地图应用
```

### ❌ 不好的协调器输出

```json
{
  "action": "tap",
  "coordinates": [500, 300],
  "element": "地图图标"
}
```

理由：这是PhoneAgent的工作，不是协调器的工作。
