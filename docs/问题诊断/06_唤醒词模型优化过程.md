# 唤醒词模型优化过程记录

**版本**：2026-04-13  
**目标**：为"小万"唤醒词构建基于原型网络的个人化检测模型，解决误触发、漏触发问题

---

## 初始状态与问题现象

初始模型训练完成后，测试时出现异常：

- **注册时**：录音嵌入与自身原型余弦相似度 `raw_sim ≈ 0.93`
- **实时检测时**：同样说"小万"，`raw_sim` 只有 `0.66`，远低于注册时

直接原因是"有时触发，有时不触发"，表现为检测不稳定。

---

## 根因分析

### 根因 1：窗口占用率不匹配

**问题**：

| 场景 | 窗口长度 | 有声帧比例 |
|------|---------|-----------|
| 注册录音 | 1.5 秒 | **89%**（录音时尽量填满） |
| 实时检测 | 1.5 秒 | **20-30%**（说"小万"仅 ~0.4s，其余是静音) |

**机制**：模型使用 `AdaptiveAvgPool2d` 对时间维度做平均池化。注册时 89% 的帧都是有效语音，嵌入向量主要由语音帧贡献；检测时 70-80% 是静音帧，平均后嵌入被稀释，与注册原型的余弦相似度从 0.93 掉到 0.66。

**表现定量诊断**：

```
[诊断] voiced_frames:  正样本 131/148 (89%) | TTS负样本 61/148 (41%)
```

---

### 根因 2：训练损失函数未真正训练唤醒词

**问题**：原始训练使用 10-way 随机情节采样（Prototypical Networks），74 个类别中只有 1 个是正类 `_pos_小万`。

随机采样时正类出现概率：

$$P(\text{正类被抽到}) = 1 - \frac{\binom{73}{10}}{\binom{74}{10}} \approx \frac{10}{74} \approx 13.5\%$$

**实际意义**：超过 86% 的训练 episode 中，模型根本看不到 `_pos_小万`，只在区分各类 TTS 语音。最终达到 74% 准确率是因为模型学会了区分各类 TTS 音频，而不是识别唤醒词本身。模型对"小万"的泛化能力从未被训练。

---

## 优化方案

### 优化 1：缩短检测窗口（1.5s → 0.8s）

**改动文件**：`wake_word/config.py`

```python
# 修改前
CLIP_DURATION = 1.5
N_SAMPLES = 24000
DETECTION_WINDOW = 1.5

# 修改后
CLIP_DURATION = 0.8
N_SAMPLES = 12800   # 16000 * 0.8
DETECTION_WINDOW = 0.8
DETECTION_STRIDE = 0.2  # 滑窗步长同步缩小（0.5→0.2）
```

**效果**：0.8s 窗口中说"小万"（~0.4s）的占用率提升到 50%+，大幅减少静音帧稀释影响。

---

### 优化 2：AdaptiveAvgPool → AdaptiveMaxPool

**改动文件**：`wake_word/model.py`（WakeWordEncoder 和 SpeakerEncoder 各一处）

```python
# 修改前
self.pool = nn.AdaptiveAvgPool2d(1)

# 修改后
self.pool = nn.AdaptiveMaxPool2d(1)
```

**原理**：MaxPool 从所有时频位置中取最大激活值，天然聚焦于能量最强的有声帧，静音帧的低激活值不再拉低整体嵌入。即使语音只占窗口的 30%，MaxPool 也能提取到完整的语音特征。

---

**调用**（`dataset.py` 中 `load_audio`）：


另外在 `_get_mel` 中增加**梅尔级静默掩码**：随机屏蔽 20-60% 的帧（设为 `mel.min() - 10dB`），进一步增强对不同有声帧密度的鲁棒性。

---

### 优化 4：修复损失设计——每次 episode 强制包含正类

**改动文件**：`wake_word/dataset.py`（`sample_episode` 方法）

```python
# 修改前：全随机（正类仅 13.5% 概率出现）
classes = random.sample(all_classes, N_WAY)

# 修改后：第 0 个 slot 固定为正类，其余 4 个从负类随机抽
pos_class = '_pos_小万'
neg_classes = random.sample(all_negatives, N_WAY - 1)
classes = [pos_class] + neg_classes
```

同时将 `N_WAY: 10 → 5`，减小难度，让早期训练先收敛到对正类的识别。

**效果**：每个 episode 都包含唤醒词，模型被迫学习"小万"与各类负样本的区分边界，而不是只学习负样本间的区分。

## 关键结论

1. **窗口长度比训练 episode 数更重要**：1.5s 窗口导致注册与检测场景严重不匹配，是导致 sim 从 0.93 掉到 0.66 的直接原因。
2. **MaxPool 比 AvgPool 更适合变长有声内容**：唤醒词在检测窗口中位置不固定，MaxPool 天然处理这种稀疏有声场景。
3. **确保正类出现在每个 episode 中是前提条件**：不做这个改动，训练 10000 个 epoch 也无法学会识别唤醒词。
4. **数据增强应模拟推理场景**：`random_silence_pad` 让训练数据分布与实际检测分布一致，是泛化能力的关键。
